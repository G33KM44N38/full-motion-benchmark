# Preuves et rapports

L’agent dépose ici, pour chaque run :

- `STRUCTURE.md`, `IMAGE-MAP.md`, `CHECKLIST.md`, `RAPPORT.md`
- `evidence/` (référence, build, montages côte à côte, diffs, itérations)
- éventuellement `.agents/skills/verify-<projet>/`

Ces fichiers sont commités sur la branche `run/<modele>` avec le site. Ils ne sont pas déployés.
