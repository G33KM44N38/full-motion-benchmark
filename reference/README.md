# Captures de référence de https://full-motion.fr/

Relevé du 22 novembre 2026. 48 images (JPEG, qualité 70, largeur max. 1440 px).

Nomenclature : `<page>-<desktop|mobile>-<viewport|full>.jpg`

- `viewport` : premier écran (1440×900 ou 390×844)
- `full` : page entière (attention, `drone-work` et `drone-category` sont très longues)

Viewports : desktop 1440×900, mobile 390×844 (`isMobile`, `hasTouch`, `deviceScaleFactor: 1`).
